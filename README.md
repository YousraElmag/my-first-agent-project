# My First Website

A simple static website built with HTML and CSS.

## Project structure

```
index.html      Home page
about.html      About page
css/style.css   All styles for the site
images/         Images and icons
```

## How to view it

Open `index.html` in your web browser (double-click the file).

Tip: in VS Code you can use the **Live Server** extension to reload the page automatically when you save.
